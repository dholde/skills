# Premium redesign

Act as a world-class senior product designer and frontend engineer. Redesign this interface to look like a premium, modern SaaS product while maintaining the app's existing design system.

Use a cohesive color palette, clear visual hierarchy, subtle animations, polished components, and beautiful responsive layouts that align with the existing design system.

Avoid generic AI-generated dashboard aesthetics, excessive cards, and unnecessary gradients. Use the existing tech stack and implement production-quality frontend code. Make thoughtful design decisions independently, then review and refine the visual result.
